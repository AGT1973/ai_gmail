Most developers build AI that responds to a single prompt. This course 
teaches you to build AI that plans, uses tools, and coordinates multiple 
agents to complete a task end to end, built from first principles in 
Python, so you see exactly how each step works.


In this course, you’ll learn how to:


      * Build agentic design patterns (reflection, tool use, planning, and
        multi-agent coordination) that let AI iterate, act, and adapt


      * Integrate AI with external tools such as databases, APIs, web
        search, and code execution to pull in real data


      * Evaluate and optimize your AI systems to be production-ready


Intermediate Python and a basic understanding of LLMs and APIs will help 
you follow along. If you build with AI today, this course will show you how 
to move past single-prompt AI to autonomous AI.
